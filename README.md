# Shadows

Trabajo práctico final de Diseño de videojuegos. Es un juego de puzzles 2D hecho en Unity donde el jugador coloca bloques de sombra para bloquear y reflejar haces de luz, y desbloquea habilidades a lo largo de los niveles.

## Cómo abrirlo

1. Clonar el repositorio.
2. Abrir la carpeta con Unity `6000.3.17f1` (Unity Hub la ofrece al agregar el proyecto).
3. Abrir la escena `Assets/Scenes/SplashScreen.unity` y darle Play. Para probar un nivel suelto, abrirlo y dar Play: el editor pasa por `CoreManagers` solo.

## Controles

- **Mover:** WASD o flechas.
- **Elegir habilidad:** teclas 1 a 4, o la rueda del mouse.
- **Usar habilidad:** clic izquierdo.
